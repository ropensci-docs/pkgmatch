# Package index

## Main functions

- [`pkgmatch_similar_fns()`](https://docs.ropensci.org/pkgmatch/reference/pkgmatch_similar_fns.md)
  : Identify R functions best matching a given input string
- [`pkgmatch_similar_pkgs()`](https://docs.ropensci.org/pkgmatch/reference/pkgmatch_similar_pkgs.md)
  : Find R packages matching an input of either text or another package

## BM25 functions

- [`pkgmatch_bm25()`](https://docs.ropensci.org/pkgmatch/reference/pkgmatch_bm25.md)
  : The "Best Matching 25" (BM25) ranking function.
- [`pkgmatch_bm25_fn_calls()`](https://docs.ropensci.org/pkgmatch/reference/pkgmatch_bm25_fn_calls.md)
  : The "Best Matching 25" (BM25) ranking function for function calls

## Treesitter functions

- [`pkgmatch_treesitter_fn_tags()`](https://docs.ropensci.org/pkgmatch/reference/pkgmatch_treesitter_fn_tags.md)
  : Identify all function calls made within a package.

## Utility functions

- [`generate_pkgmatch_example_data()`](https://docs.ropensci.org/pkgmatch/reference/generate_pkgmatch_example_data.md)
  : Generate example data to use with pkgmatch

- [`head(`*`<pkgmatch>`*`)`](https://docs.ropensci.org/pkgmatch/reference/head.pkgmatch.md)
  : Head method for 'pkgmatch' objects

- [`pkgmatch_browse()`](https://docs.ropensci.org/pkgmatch/reference/pkgmatch_browse.md)
  :

  Open web pages for `pkgmatch` results

- [`pkgmatch_load_data()`](https://docs.ropensci.org/pkgmatch/reference/pkgmatch_load_data.md)
  : Load 'pkgmatch' data for specified corpus.

- [`pkgmatch_update_cache()`](https://docs.ropensci.org/pkgmatch/reference/pkgmatch_update_cache.md)
  :

  Update all locally-cached `pkgmatch` data to latest versions.

- [`print(`*`<pkgmatch>`*`)`](https://docs.ropensci.org/pkgmatch/reference/print.pkgmatch.md)
  : Print method for 'pkgmatch' objects

- [`pkgmatch_update_data()`](https://docs.ropensci.org/pkgmatch/reference/pkgmatch_update_data.md)
